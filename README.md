# Adulis — App Downloads

Official installer downloads for the Adulis merchant app (Ethiopia).

| File | Size | For |
|------|------|-----|
| `Adulis.apk` | ~9 MB | Most phones (64-bit, roughly 2017 and newer) |
| `Adulis-full.apk` | ~24 MB | Older 32-bit phones (e.g. itel) |

Both are the same app, release-signed. If a phone says "app not compatible" when installing `Adulis.apk`, use `Adulis-full.apk` instead.

Install tip: if Google Play Protect shows a warning during install, choose **More details → Install anyway** (or Decline the scan) — the app is safe; the warning appears because it did not come from the Play Store.
